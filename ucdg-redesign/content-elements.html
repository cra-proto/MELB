Content elements

The building blocks readers see inside a section — the text itself, the way it is emphasized, the links that lead onward, and the lists and tables that organize information. These are the components you reach for most, so getting them right is what makes a page easy to read and act on.

Components in this family

Typography
The fonts, sizes, and line length the design system sets for you — what you inherit, and the one rule (reading measure) you control
Text formatting
How to emphasize text with bold, italic, alignment, size, and colour — sparingly, and never as the only signal
Text editing effects
Reveal-on-demand effects that show or hide text — used rarely, and only when the hidden content is genuinely secondary
Links
How to write link text, where to place links, and how to handle new tabs, buttons, email, and vanity URLs accessibly
Lists
Bulleted, numbered, and description lists — including icon lists, columns, menus, and interactive checklists
Tables
When a table is the right tool, when a list or plain text serves better, and how to build a table that works on a phone and with a screen reader

Choosing between them

Presenting a set of items?

Reach for Lists first. Use a Table only when each item has the same two or more attributes that the reader needs to compare across rows.

Emphasizing or linking text?

Use Text formatting to stress a word, and Links to send the reader onward — both sparingly, so the emphasis and the links keep their meaning.
