Doormats

A doormat is a link with a short description under it, used on a hub, topic, or subway index page to help a reader choose the right destination. The title says where the link goes; the description helps the reader tell it apart from its neighbours. Together they turn a wall of links into a set of clear choices.

Choose the right pattern

Use a doormat only when the reader needs a description to choose between links. If the links are self-explanatory, a plain list is lighter and better.

  • Doormat

    Use when the page's job is to route the reader and each link needs a short description to distinguish it — landing, topic, and subway index pages.

  • Plain list of links

    Use when the link titles are self-explanatory and need no description — a list of provinces, a set of forms by number.

  • Most requested

    Use for the handful of top tasks. If you use both patterns on a page, don't repeat the same links in the doormats.

Quick decision guide

  • Do readers need a description to choose between the links? → Doormat
  • Are the link titles clear on their own? → Plain list
  • Is it the short set of top tasks? → Most requested (don't duplicate in doormats)

What to include

A doormat has two parts, in a fixed structure:

  • Link title — a hyperlink, ideally around 45 characters, that names the destination page
  • Link description — plain text under 100 characters, a comma-separated phrase, with no period at the end

Across a set of doormats, also include:

  • Parallel structure — every title phrased the same way, every description the same shape
  • An order that reflects what matters most to the reader
  • Wording that distinguishes each link from the others, so no two feel interchangeable

Guidance

  • Keep the title short and specific — it is a promise about the destination, so make it match the target page's title.
  • Write descriptions that help the reader choose, not marketing copy. Name what's on the page, comma-separated, no period.
  • Don't use icons or images to add emphasis to doormats — they compete with the titles and add nothing to the choice.
  • Don't repeat links already in a "Most requested" block on the same page.
  • Follow the length and style rules. A doormat that ignores them stops looking like part of a cohesive set.

Placement

  • Doormats are the core content of the pages that use them — institutional landing pages, topic pages, and subway index pages (where they're mandatory).
  • Group related doormats together, ordered by importance to the reader.
  • When a "Most requested" block is also present, place it first for the top tasks, then the doormats for the fuller set.

Accessibility

  • The link title must make sense on its own — screen-reader users may hear it out of context in a list of links.
  • The description is supporting text, not part of the link — keep it outside the anchor so the link name stays concise.
  • Don't rely on layout or colour alone to group doormats; use real headings to label each group.
  • Keep titles unique across the set so two links never read identically to someone navigating by links.

Examples

Compare doormats side by side

Good doormats
  • Canada child benefit (CCB)
    monthly payment for families raising children under 18
    Why it works: specific title, short comma-separated description under 100 characters, no period.
  • GST/HST credit
    quarterly payment to offset sales tax for people with low incomes
    Why it works: parallel to its neighbours, and the description distinguishes it from other benefit links.
Doormats to avoid
  • Learn more about this important benefit that could help you
    Find out everything you need to know about eligibility and how to apply today.
    Why it is wrong: title far over 45 characters, description is marketing copy over 100 characters with a period.
  • A grid of doormats each fronted by a large coloured icon.
    Why it is wrong: icons add emphasis that competes with the titles; doormats shouldn't use images for emphasis.
  • A doormat list of the 13 provinces and territories, each with a one-line description.
    Why it is wrong: the titles are self-explanatory and need no description. Use a plain list.
