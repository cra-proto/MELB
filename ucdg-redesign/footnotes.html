Footnotes

A footnote moves a reference, citation, or aside out of the main text and to the bottom of the page, linked both ways. It keeps the sentence clean while still giving the detail to readers who want it. On the web, most footnotes are a sign the information belongs somewhere better — so use them rarely.

On this page

  • When to use it
  • Guidance
  • Accessibility
  • Examples

When to use it

  • Use a footnote for a genuine reference, citation, or source note that would clutter the sentence if left inline.
  • Give every footnote a two-way link: a marker in the text that jumps down, and a return link that jumps back.
  • Number footnotes in the order they appear and collect them under a "Footnotes" heading at the bottom.

Guidance

  • Prefer editing over footnoting. If the detail matters, work it into the sentence; if it doesn't, cut it.
  • Don't use footnotes for content the reader needs to act — deadlines, amounts, and steps belong in the main text, never in a note.
  • Don't use a footnote where an inline link would do the same job more directly.
  • Keep footnotes few. A page dense with markers is hard to read and to follow on a phone.

Accessibility

  • Use the design system's footnote markup so the marker, the note, and the return link are correctly associated for screen readers.
  • Give the footnote marker accessible text (for example, "Footnote 1") rather than a bare superscript number.
  • Make the return link say where it returns to, so a screen-reader user isn't dropped without context.

Good use of footnotes
  • A statistics page cites the source of a figure in a numbered footnote, with a marker in the text and a return link in the note.
  • A guide adds a brief legal citation as a footnote so the sentence stays readable, while the reference is still available.
Footnotes to avoid
  • The filing deadline placed in a footnote.
    Why it is wrong: essential information must be in the main text, not a note the reader may never open.
  • A paragraph with six footnote markers.
    Why it is wrong: too many notes break the reading flow. Edit the detail into the text or cut it.
  • A footnote used where a plain inline link to the source would be simpler.
    Why it is wrong: the footnote adds a hop with no benefit. Link directly.
