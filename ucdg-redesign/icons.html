Icons

An icon is a small symbol that supports nearby text — a checkmark beside "included", a phone beside a number. GCWeb provides two icon sets, Glyphicons and Font Awesome. Icons help scanning, but they are decoration on top of words: the meaning must live in the text, and the icon must never be the only way to understand it.

Choose the right pattern

Decide what the icon is doing — decorating text, or standing in for it. The second is almost always the wrong choice.

  • Decorative icon (with text)

    The right use. An icon reinforces a visible label — a green check beside "Included". Mark it aria-hidden; the text carries the meaning.

  • Icon alone (no text)

    Avoid. An icon with no label is a guess for the reader. If you must, give it accessible text so its meaning is available.

Quick decision guide

  • Is there a visible text label next to the icon? → Decorative, hide it from assistive tech
  • Is the icon the only thing conveying meaning? → Add a text label, or give the icon accessible text
  • Are you adding an icon just to fill space? → Don't

What to include

  • An icon from one of the two supported sets (Glyphicons or Font Awesome), used consistently
  • A visible text label the icon supports
  • The same icon for the same meaning everywhere it appears

Guidance

  • Use icons to support text, not replace it. A checkmark reinforces "Included"; it doesn't stand in for the word.
  • Be consistent — one icon, one meaning. Don't use a check for "done" in one place and "correct" in another with a different look.
  • Don't decorate doormats or headings with icons for emphasis (see Doormats).
  • Choose common, well-understood symbols. An obscure icon needs a label anyway, so lead with the label.

Accessibility

  • Decorative icons (those next to a visible label) must be hidden from assistive technology with aria-hidden="true", so they aren't announced as noise.
  • An icon that carries meaning on its own must have a text alternative a screen reader can read.
  • Never use colour alone to give an icon meaning — a red X and a green check must also differ in shape and be backed by text.
  • Ensure icons meet contrast against their background when they carry meaning.

Examples

Compare icons side by side

Good use of icons
  • A "What's included" list uses green checks and red X marks beside the words "Included" and "Not included", with the icons hidden from screen readers.
  • A phone icon sits beside the contact number as a scanning aid, with the number itself as plain text.
Icons to avoid
  • A row of icons with no labels used as the main navigation.
    Why it is wrong: readers must guess each icon's meaning. Add text labels.
  • A green check and red X with no accompanying words, distinguished only by colour.
    Why it is wrong: colour-blind and screen-reader users can't tell them apart. Back them with text.
  • Large decorative icons added to every doormat for visual interest.
    Why it is wrong: they compete with the link titles and add no meaning. Doormats shouldn't use icons for emphasis.
