Interaction & feedback

Components that talk back to the user. Use these when you need to warn someone about a situation, ask them a question and branch the page based on their answer, or explain the difference between "and" and "or" in a rule that would otherwise be misread.

Components in this family

Alerts
A short, temporary notice at the top of a page or section — used when something has changed, gone wrong, or needs the user's attention right now
Interactive questions
A guided question the user answers on the page to reveal only the content that applies to them — used for eligibility, format choices, and any "it depends" scenario
And / Or
A visual pattern that makes the difference between "all of these" and "any of these" unmistakable in a list of criteria — used inside eligibility and rule blocks

Choosing between them

Use Alerts

When you need to tell the user something urgent, temporary, or reactive — before they continue.

Use Interactive questions

When you need to ask the user something first, then show only the guidance that applies.

Use And / Or

When a list of rules or criteria could be misread — make the combinator visible.
